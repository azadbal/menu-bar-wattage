# Menu Bar Wattage product identity

The macOS utility is named **Menu Bar Wattage** across its shipped app, app-specific source/project identifiers, bundle identifiers, release artifacts, documentation, and GitHub repository. The internal `PowerCore` library and domain terms such as adapter wattage remain unchanged; because no public release exists, the rename uses new app bundle identifiers and does not add a compatibility migration for `Statusbar Power`.
